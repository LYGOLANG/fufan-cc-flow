# 出厂设计规范

> 这套是兜底：没有样板、没有更好的想法、要快的时候用。有样板就读样板的值替换进 tokens.css；有自己的设计就做自己的，只要成体系。原则和反丑清单不管走哪条路都适用。
> 值在 tokens.css，基础零件在 base.css，全部零件和状态看 kit.html（浮岛：三座圆角岛、无边框靠明度分层、一个强调色）。画布、剪辑、电商生图、写作、看板各有零件包（canvas / timeline / gallery / editor / charts .css）和对应的 kit-*.html。每一类场景的规矩在 场景规矩.md。

## 原则
- 层级靠字重和明度，不靠颜色、不靠放大。标题 600，正文 400，弱化的用 --t3。
- 界面本体是灰阶。彩色只有三处：一个强调色（选中、焦点、链接）、状态色（成功、警告、错误）、状态点。主按钮是黑白反色，不用强调色。
- 面靠明度分层，不靠边框和投影：卡片是升一级的底，无边框无投影；投影只给弹层。分割线只在列表行之间，且很淡。
- 圆角四档：岛 18、面板 14、控件 10、小件 6；胶囊只给按钮和徽标。
- 留白是内容，不是剩下的空：区块之间 48，卡片内 24，行高 48；宁可少放东西。
- 数字用等宽，右对齐；中英文之间留一个空格；按钮是动词。
- 动效快而少：140 毫秒，只用于悬停、选中、展开；进度过渡 300 毫秒；不做环境动画。
- 对比度：正文和元信息（含 11–12px 的灰字）至少 4.5:1，控件的边至少能看出来（填色加一根细线，或 3:1 的边）。状态色做文字用时也要过 4.5:1。

## 反丑清单（交稿前逐条对，一条不过不交）
1. 一屏只有一个强调色；没有第二种彩色用在非状态的地方。
2. 没有多余的边框：卡片、面板、区块都没有描边；分割线只出现在列表行之间。
3. 间距只用你这套体系的阶梯里的数（出厂是 4、8、12、16、24、32、48、64）；没有一处一个数。
4. 标题靠字重和位置，不靠一味放大；字阶不超过五档，每档有用途。
5. 字体是系统无衬线，中文回退苹方；代码和数字用等宽。没有 emoji 当图标，图标用线性 SVG、同一粗细。
6. 没有渐变、没有毛玻璃、没有大面积投影。
7. 内容是真的句子和真的数字（虚构但像真的），不是"标题标题标题""Lorem ipsum"。
8. 对称位置的留白相等；同一行的标题在同一水平线；右侧动作在同一条竖线上。用 scripts/edges.py 量，不凭眼睛。
9. 每个可点的东西看得出能点：按钮有按钮的样子，文字链接只用于行内展开和外链。
10. 文字和背景对比够（正文至少 4.5:1）；状态不只靠颜色，配文字或图标。
11. 窄屏不超框、不压框、不堆叠：侧栏收成图标、标签上移、按钮换行或收进菜单。用 scripts/overflow-check.js 查。
12. 深浅两套都有的话，两套都截图看过；没有写死的颜色，全走变量。
13. 文字离它所在容器的边至少 8：每个装文字的框都有内边距，多行输入用多行的样式，文字再长也不贴边、不溢出。

## 交互清单（和反丑清单一起过，一条不过不交）
1. 可点的用 button 或 a，不是 div / span；状态写在 aria-checked / aria-pressed / aria-current / aria-selected 上。
2. 每个可点的东西有五态：默认、悬停、按下、键盘焦点、禁用；加载中的按钮不可再点。
3. 悬停才出现的东西在触屏上常显（@media (hover: none)）。
4. 点击目标至少 40，手机上 44；视觉上小的用透明热区扩大点击范围。
5. 键盘走得通：Tab 到每个控件，菜单和选项 ↑↓ ⏎ Esc，对话框锁焦点、关了回到触发处，快捷键有提示。
6. 反馈不只靠颜色：状态配文字或图标；改变用 role=status 念出来；表单错误说清怎么改。
7. 只有不可逆的操作弹确认，按钮写动词；能撤销的不弹，做完给带"撤销"的提示条。
8. 等待有交代：小于 1 秒不显示，1 到 3 秒骨架或圈，更久有进度和剩余时间、能取消。
9. 每个列表三种态都画了：空、加载中、出错。
10. 窄屏有安排：收起的东西能打开（抽屉、底部面板），底部 Tab 有字，输入不被键盘挡。
11. 主任务区的直接操作（拖、框选、修剪、缩放）有光标变化和吸附反馈，每帧不卡。
12. prefers-reduced-motion 时动效全关。
