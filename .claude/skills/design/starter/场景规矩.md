# 场景规矩

> 这里写的是：这一类至少要有什么、最容易做丑的地方在哪。零件用出厂的或自己成体系的都行，规矩不变。画布、剪辑、电商生图、写作、看板五类有出厂零件包，看同目录的 kit-canvas / kit-timeline / kit-gallery / kit-editor / kit-charts.html；其余类用 kit.html 里的基础零件拼。

## 按终端

**网站 / 桌面软件**：同一套壳——导航岛、内容区、可收的辅助岛。桌面软件多一条：窗口顶部留出系统按钮和拖拽区，不把内容顶到边上。窗口变窄的让路顺序：先收辅助岛，再缩内容区留白，再把导航收成图标；内容区最窄不低于 480，到了就收东西，不挤。

**手机**：导航在底部 Tab（最多五个），内容一栏，弹层从底部升起（底部面板），留安全区；单手够得着的地方放主动作；字不小于 14，点击区不小于 44；不做悬停，没有"悬停才出现"的按钮。

**命令行**：也有排版——对齐的列、等宽的数字、一种强调色、进度用一行刷新不刷屏；出错先说错在哪再说怎么办；长输出分页或折叠。

**浏览器扩展 / 嵌入面板**：只有一条 320 到 400 宽的栏，没有导航岛，头部一行标题加一个动作；不和宿主页面抢颜色，用宿主的深浅。

## 按业务场景

**工作台类**（列表、详情、任务、设置、用量）：首屏只放三件事——最重要的事、下一步动作、系统在干什么；列表靠行高和一根淡线分隔，不用卡片框；详情页有页头返回箭头；设置页用三列表单，说明紧跟控件，长说明收进问号；数字全走等宽右对齐。最容易丑：像后台——到处是边框、表头、彩色徽标；给读者的页面混进内部数字。

**Agent 类**：对话区只在用户找它做事时说话，后台任务不进对话区；过程行常显（工具调用一行一件）、结果默认收起可展开，改文件的 diff 和出错的默认展开；提问用输入框上方升起的选择抽屉，不在消息里放按钮；审批卡说清要改哪个文件、要跑哪条命令；输入框上标着权限和模型；停止、中断、超时都在对话里留一句。最容易丑：把过程压成一句"已完成"，用户不知道它干了什么。

**写作 / 创作台**：编辑器铺满内容区，行号、文件头折叠、保存状态、预览是开关不是并排；正文 16 到 17 号、行高 1.7 以上、行长 40 到 50 个汉字靠字号控制不靠 max-width；稿件的状态流（草稿 → 待验收 → 已验收）在页头；助手改了稿要说改了哪几处。最容易丑：编辑器窄、预览挤在旁边、右边空一片。

**阅读 / 信息流**：一条一行或一卡，标题、一句摘要、来源、时间、等级；按天分组的标题贴顶；转载折叠"另 N 个来源"；无限下拉不做分页按钮；正文页元信息一行、来源名可点、末尾再给一次原文链接。

**画布类**：画布是主任务区，不可压缩，占满剩下的全部；工具条浮在画布上（左或下），属性面板浮在右边可收，图层列表可收；选中有手柄，缩放读数在角上；右键菜单短；快捷键提示在工具旁。最容易丑：给画布加边框、把属性面板做成常驻的大侧栏挤画布。

**剪辑类**：预览窗和多轨时间线是主任务区，不可压缩；时间线有播放头、缩放、吸附、片段块（拖得动、看得出长短）；时间码等宽；波形淡色；字幕列表跟播放头联动；素材库能拖进时间线；导出面板写清格式、分辨率、预计大小、进度。最容易丑：轨道挤成一团、播放头看不见、素材库占了半屏。

**电商生图类**：图片网格比例一致、间距一致、可多选、多选后底部浮条给批量动作；生成参数面板在一侧（提示词、参考图、比例、张数、风格预设用芯片），主动作一个；生成中要看得见排队、进度、耗时、花了多少钱；结果能前后对比、能放大（灯箱）、能一键下载；商品卡是图、标题、价格三样，不堆标签。最容易丑：图片大小参差、参数面板像表单、一屏五个按钮。

**数据看板**：先定形再定色——单序列一种色相由浅到深，两个序列才有图例；柱子顶端圆角齐基线、网格一根淡线；热力图格子固定按宽度砍数量；大数字用等宽、一屏一个领头的大数；读数用跟着鼠标的提示，不在图下另放一行。最容易丑：彩虹色、双轴、饼图、每根柱上标数。

**落地页**：首屏一句话说清是什么给谁、一个主动作；特性三栏、定价卡、问答折叠、页脚；留白大、字大、颜色少；截图用真的产品图。最容易丑：渐变、光效、五种颜色、"功能强大"这类空话。

## 横切的

登录和首次启动：一屏只做一件事，说清接下来会发生什么。空状态：一句话说这里会出现什么，加一个动作，不放插画。破坏性操作：只有不可逆的弹确认，其余给撤销。深浅两套：按需求文档定，做了就两套都截图看。
