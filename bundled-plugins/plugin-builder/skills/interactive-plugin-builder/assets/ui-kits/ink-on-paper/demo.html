INKSET 是给插件生成系统用的单色界面语法。它把 lieflat-charts 的 Mono 图表语法从"图"推到"整个界面"： 明度即层级，实心不发光，结构靠发丝线不靠阴影。同一套 token 可以直接换给时间线、波形、3D 视口、 节点画布、数据网格或标注工具——因为它们共享的从来不是控件外形，而是纸、墨、尺三层。

09

迁移法则

任何 Web 组件接入这套系统的三步
01

先拆成纸 / 墨 / 尺三层

任何组件都能拆成：纸（背景与容器面）、墨（内容与填充）、尺（刻度、网格、导轨这些没有数据的家具）。先做尺，再落墨——只画数据不画尺的界面必然寒酸。

02

用明度替换掉所有颜色

原组件里每一种颜色，问它编码的是什么：重要性→取墨梯；类别→取形状（实心/空心/虚线/斜纹）；破坏→校对红；AI→蓝黑墨。答不出来的颜色，直接删。

03

删掉阴影与位移

层级用纸面明度 + 1px 发丝线表达，交互反馈用明度变化而不是抬升。悬停不许动位置——专业工具里元素密集，位移会让整片界面抖。

DO · 应该
数值和视觉严格成正比；进度条 68% 就画 68%。
面积编码用 sqrt(v) 换算半径，不拿数值当半径。
每屏最多一张墨卡；密集工具界面里最好一张都不用。
动效 quarticOut 快进快停；入场 220ms 内结束。
演示数据用确定性伪随机，刷新两次必须长一样。
DON'T · 禁止
彩色、渐变、发光、玻璃拟态、3D 拟物——不属于纸墨。
柱状图断轴；长度∝数值是契约，断轴就是毁约。
给纯装饰元素加 hover——没有内容却有交互是欺骗。
用蓝墨做强调色，用红墨做品牌色。两支墨都只有一个职责。
装不下就缩小字号。SVG 最小 6.5px，UI 最小 9.5px，装不下改 hover 出。
拆包方式

本文件顶部 PART A 是完整组件包，整段复制即可作为 inkset.css 使用。零硬编码色值，全部走 --ip-* 变量；换纸只需替换 [data-theme] 一段。
